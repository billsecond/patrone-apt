Patrone Linux packages

The apt repository Patrone Linux gets its own updates from. GitHub hosts it; Patrone runs no servers of its own.

Patrone Linux already uses it: it comes with this repository's source and key, and its updates arrive through Patrone Software and the daily automatic updates. Nothing here needs doing on a Patrone Linux computer.

What's in it

Patrone's own packages (the desktop, taskbar, apps, branding and fonts), and Patrone's builds of a few of Ubuntu's packages that carry Patrone's changes: GDM (the login screen), GNOME Settings and first-login setup. Those are Ubuntu's version plus patrone and a number, rebuilt whenever Ubuntu updates them.

The key

Everything is signed with the Patrone Linux Archive key, patrone-archive-keyring.asc, fingerprint

8FE6 1B83 753C 2636 CD74  0259 4FC3 52E3 D384 225F

Adding it by hand

For Ubuntu 26.04 LTS (resolute), amd64:

sudo curl -fsSLo /usr/share/keyrings/patrone-archive-keyring.gpg https://billsecond.github.io/patrone-apt/patrone-archive-keyring.gpg
sudo curl -fsSLo /etc/apt/sources.list.d/patrone.sources https://billsecond.github.io/patrone-apt/patrone.sources
sudo apt update

The source is at github.com/billsecond/patrone-apt.
